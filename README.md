# GeoLists

Локальное картографическое веб-приложение для работы с географическими точками Санкт-Петербурга. На первом этапе реализованы интерактивная карта, выбор временной точки и переключение между онлайн-источником и локальным PMTiles-архивом.

## Установка и запуск

Требуется актуальная LTS-версия Node.js (для Vite 7 — Node.js 20.19+ или 22.12+).

```bash
npm install
npm run dev
```

Дополнительные команды:

```bash
npm run typecheck
npm run build
```

## Онлайн-режим

Онлайн-режим использует публичный стиль [OpenFreeMap](https://openfreemap.org/) `Liberty`. Картографические данные основаны на OpenStreetMap; атрибуция отображается средствами MapLibre. Для загрузки стиля, тайлов, шрифтов и спрайтов требуется доступ в интернет. Доступность сервиса зависит от внешнего поставщика.

## Подключение `spb.pmtiles`

1. Получите настоящий PMTiles-архив Санкт-Петербурга с данными в схеме [Protomaps Basemap](https://docs.protomaps.com/basemaps/).
2. Назовите его `spb.pmtiles` и положите в `public/maps/spb.pmtiles`.
3. Запустите приложение и выберите «Локальная» в панели источников.

Приложение проверяет сигнатуру архива перед переключением. Пустой или фиктивный файл не принимается. PMTiles подключается через официальный адаптер `pmtiles` для MapLibre.

## Полноценная офлайн-карта

Полноценная офлайн-карта требует не только локального архива векторных тайлов, но и совместимых локальных ресурсов стиля: glyphs (шрифтовых диапазонов) и sprite (спрайтов и их описания). Текущий встроенный локальный стиль намеренно не содержит подписей и использует только слои Protomaps Basemap, которым не нужны внешние ресурсы. В дальнейшем к нему можно добавить symbol-слои и указать локальные URL `glyphs` и `sprite`.

Не следует массово скачивать стандартные тайлы OpenStreetMap: это противоречит политике их публичных серверов. Для офлайн-режима используйте подготовленный законным способом PMTiles-архив.

## Известные ограничения

- Списки и кнопка их создания пока не работают.
- Выбранная точка хранится только в памяти до перезагрузки страницы.
- Нет IndexedDB, импорта/экспорта `.mapdata`, обновления карт, авторизации и backend.
- Локальный стиль не содержит подписей; для них нужны локальные шрифты и спрайты.
- Архив должен использовать совместимую схему слоёв Protomaps Basemap.
