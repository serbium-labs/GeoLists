# GeoLists

Веб-приложение для списков географических точек Санкт-Петербурга. Данные списков хранятся в IndexedDB; карта переключается между OpenFreeMap и полностью локальным архивом Protomaps PMTiles.

## Разработка

Нужен Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Vite-режим удобен для разработки, но не предоставляет API обновлений. Полный локальный запуск:

```bash
npm run build
npm run serve
# http://127.0.0.1:4173
```

## Первоначальная установка офлайн-карты

Скрипт использует официальный `pmtiles` CLI и команду `extract` для выборочного получения прямоугольника Санкт-Петербурга из ежедневной сборки [Protomaps Basemap](https://docs.protomaps.com/basemaps/downloads). Весь планетарный архив не скачивается. Стандартные публичные tile-серверы OpenStreetMap не используются.

1. Установите [pmtiles CLI](https://docs.protomaps.com/pmtiles/cli).
2. Найдите существующую дату сборки на [maps.protomaps.com/builds](https://maps.protomaps.com/builds/).
3. Выполните подготовку до `npm run build`:

```bash
BUILD_DATE=20261012 npm run map:prepare
npm run build
npm run serve
```

`map:prepare` извлекает bbox `29.40,59.63,31.05,60.25` до zoom 15 в `data/maps`, запускает `pmtiles verify`, считает SHA-256 и создаёт используемый сервером указатель `active.json`. Границы можно переопределить через `SPB_BOUNDS`. Скрипт также получает из [protomaps/basemaps-assets](https://github.com/protomaps/basemaps-assets) необходимые локальные диапазоны Noto Sans (Latin, Cyrillic и пунктуация) и их лицензию. После сборки офлайн-стиль не содержит внешних URL: здания, дороги и подписи читаются только с `127.0.0.1`.

Архивы и активный указатель исключены из Git намеренно. Можно вручную положить совместимый архив в `public/maps/spb.pmtiles`, но такой режим не имеет метаданных версии и не подходит для управляемых обновлений.

## Обновления

Для проверки обновлений нужен небольшой JSON-манифест на вашем HTTPS-хостинге и региональный PMTiles:

```json
{
  "version": "2026-10-12",
  "url": "https://maps.example.org/geolists/spb-20261012.pmtiles",
  "sha256": "0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef",
  "size": 123456789
}
```

Сначала подготовьте региональный архив тем же `map:prepare`, затем опубликуйте именно этот файл и его фактические `sha256`/`size`. Запуск:

```bash
MAP_UPDATE_MANIFEST_URL=https://maps.example.org/geolists/latest.json npm run serve
```

«Проверить» сравнивает `version` с активной. «Скачать» пишет данные в отдельный временный файл и показывает серверный прогресс. Сервер проверяет заявленный размер, SHA-256 и заголовок PMTiles v3; только после всех проверок он переименовывает файл и атомарно заменяет `active.json`. При ошибке временный файл удаляется, а предыдущий архив остаётся активным. После успеха перезагрузите страницу, чтобы сбросить внутренний кэш PMTiles.

Protomaps не публикует готовый стабильный URL именно для вырезки СПб: официальный источник — планетарная ежедневная сборка, а региональный артефакт создаёт и размещает оператор приложения.

## Офлайн- и онлайн-режимы

Выбранный режим сохраняется в `localStorage`. При старте в локальном режиме приложение не запрашивает онлайн-стиль. PMTiles, glyph PBF, JS и CSS обслуживаются локальным сервером; PMTiles читается Range-запросами. Онлайн-режим использует публичный стиль [OpenFreeMap Liberty](https://openfreemap.org/) и требует интернет для стиля, тайлов, шрифтов и спрайтов.

Для автономной работы после установки нужен локальный сервер: открытие `index.html` через `file://` не поддерживает корректные Range-запросы и API обновлений.

## Хранение, источники и лицензии

- Большой PMTiles хранится в файловой системе, а не IndexedDB/Cache API: браузерные квоты зависят от браузера и могут очищаться автоматически.
- Protomaps Basemap основан на OpenStreetMap и распространяется как Produced Work по ODbL; в карте сохранена атрибуция © OpenStreetMap contributors.
- Noto Sans glyphs распространяются по SIL Open Font License; лицензию скрипт загружает рядом с файлами.
- Для архива zoom 15 не следует ожидать деталей, доступных только на zoom 16+. Размер зависит от даты и bbox.
- Сервер слушает только `127.0.0.1`. Для общего доступа нужны TLS, авторизация и reverse proxy.
